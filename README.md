# 🌿 Komodo Hub

**Komodo Hub** is a digital platform dedicated to wildlife conservation in Indonesia. It connects communities, schools, and conservation enthusiasts to share knowledge, track endangered species, and promote sustainable initiatives.

🌍 **Website**: [komodohub.org](https://komodohub.org)  
📧 **Support Email**: [support@komodohub.org](mailto:support@komodohub.org)


## 🦎 About Komodo Hub
Komodo Hub is an initiative by **Yayasan Komodo**, aiming to:
- Protect and monitor **Indonesian endemic species**.
- Educate people about **wildlife conservation**.
- Involve local **communities and schools** in preservation efforts.
