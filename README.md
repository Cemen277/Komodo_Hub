# 🌿 Komodo Hub (January 2025 - April 2025)

**Komodo Hub** is a digital mobile platform dedicated to wildlife conservation in Indonesia. It connects communities, schools, and conservation enthusiasts to share knowledge, track endangered species, and promote sustainable initiatives.

🌍 **Website**: [komodohub.org](https://komodohub.org) (Please use via mobile for the full experience).

⚠️ Heads up!
Because we’re using free hosting services, our server may go into sleep mode when inactive. If you're the first to use the site after a while, it might take up to 1–2 minutes to fully wake up. Thanks for your patience!

📧 **Support Email**: [support@komodohub.org](mailto:support@komodohub.org)


## 🦎 About Komodo Hub
Komodo Hub is a platform, aiming to:
- Protect and monitor **Indonesian endemic species**.
- Educate people about **wildlife conservation**.
- Involve local **communities and schools** in preservation efforts.
